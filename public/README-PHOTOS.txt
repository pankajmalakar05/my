Apni photos aur music yahan is folder me daalein (drag & drop / copy-paste):

1) photo1.jpg   -> Front Cover wali round photo
2) photo2.jpg   -> Inside Left page wali photo
3) music.mp3    -> Background song (optional). "Play Music" button se bajega.

File ka naam bilkul waisa hi rakhein jaisa upar likha hai
(agar photo .png hai to naam .jpg kar dein, ya humein bata dein hum code adjust kar denge).

File daalne ke baad browser refresh karein — photo/music apne aap available ho jayegi.
Photo hatani ho to file yahan se delete kar dein, wapas placeholder dikhega.
